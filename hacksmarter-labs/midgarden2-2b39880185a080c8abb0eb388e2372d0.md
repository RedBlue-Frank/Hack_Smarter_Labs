* I did a bit of research and came up with the below resources that can well explain how to exploit \*\*`BadSuccessor`.\*\*AD-BadSuccessor

The BadSuccessor vulnerability, originally disclosed by Akamai researcher Yuval Gordon, exploits a design flaw in Windows Server 2025’s dMSA implementation.This vulnerability allows attackers to manipulate two critical attributes:

* `msDS-ManagedAccountPrecededByLink`
* `msDS-DelegatedMSAState`

By setting these attributes on any dMSA object (existing or newly created), an attacker can convince the Kerberos Distribution Center (KDC) to issue tickets carrying the Security Identifiers (SIDs) of high-privilege users, effectively “succeeding” them without ever touching the target account’s groups or credentials.

## Exploiting with Windows

Tools - https://github.com/logangoins/SharpSuccessor/ https://github.com/akamai/BadSuccessor

**Phase 1: Environmental Reconnaissance**

You can use the `Get-BadSuccessorOUPermissions.ps1 script` to identify accounts that can create `dMSA` in their organization units (OUs). It searches for accounts that have certain privileges.

![image.png](<../.gitbook/assets/image 20 (3).png>)

* The AD group **`webServerAdmins`** has **delegated permissions** over `OU=Web Servers,OU=Yggdrasil Servers,DC=yggdrasil,DC=hacksmarter`
* This typically means **you can manage objects in that OU** depending on the delegation (create, reset password, move, modify attributes, etc

**Phase 2:** A solid proof of concept (PoC) is `SharpSuccessor`

```bash
 .\SharpSuccessor.exe add /path:"OU=Web Servers,OU=Yggdrasil Servers,DC=yggdrasil,DC=hacksmarter" /account:**webServerAdmins** /name:pentest_dmsa /impersonate:Administrator
```

![image.png](<../.gitbook/assets/image 21 (3).png>)

* Our Operation was not successful because Windows Defender / AMSI / Real-Time Protection is blocking SharpSuccessor.exe at execution time.
* Windows Defender is **actively deleting SharpSuccessor.exe the moment you try to run it**, which is why it disappears from the directory right after the failed execution attempt.
* Lets try other alternatives to run the exploit otherwise we will resort to `obfuscation`.
